# دليل التشغيل السريع

## المتطلبات
- XAMPP (Apache + MySQL)
- PHP 8.0+ و Composer
- Node.js و npm

## خطوات التشغيل

### 1. إعداد قاعدة البيانات
- شغّل XAMPP (Apache + MySQL)
- أنشئ قاعدة بيانات: `laravel_react_db` من phpMyAdmin

### 2. إعداد Laravel Backend
```bash
composer update
php artisan key:generate
php artisan migrate
php artisan serve
```

### 3. إعداد React Frontend
```bash
cd react
npm install
npm run dev
```

## الوصول للتطبيق
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000/api

## ملاحظات
- تأكد من تشغيل MySQL في XAMPP قبل تشغيل migrations
- ملف `.env` يجب أن يحتوي على: `DB_DATABASE=laravel_react_db`
- ملف `react/.env` يجب أن يحتوي على: `VITE_API_BASE_URL=http://localhost:8000`
